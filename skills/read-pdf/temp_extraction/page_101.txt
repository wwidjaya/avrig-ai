Database management is broader in scope than database administration, including the responsibilities beyond those of database administrators. DataBase Management System (DBMS) The computer software program used to manage and query a database. database management system, hierarchical A type of Database Management System, where parent-child relationships are established between data segments. DataBase Management System, Multi-Dimensional  (MDDBMS) A specialized Database Management System that supports OnLine Analytical Processing, enabling users to analyze large amounts of data. An MDDBMS captures and presents arrays of data that can be arranged in multiple dimensions. DataBase Management System, Object-Oriented  (OODBMS, ODBMS) Database software that stores data as objects, instead of storing the data in a relational format, and then instantiating objects in memory.
