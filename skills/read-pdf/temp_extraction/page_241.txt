**T**: table In data management, a cluster of data attributes; a collection of data values associated with a population of entities, each of which is described by the same set of attributes. A cluster of one or more columns to represent information about the entities. Each attribute must be atomic (single valued). SEE ALSO flat file; relation. table scan The process of examining all rows of data in a table sequentially. table think When the data modeler thinks first of tables when developing a data model for a user domain. At the outset, everything must be represented in tables. As a consequence, they sometimes incorrectly include data items in a table such that it violates the rules of normalization. NOTE: fact oriented modeling schemes such as ORM do not model in terms of tables, rather just objects (encompassing both entities and attributes) and relationships, hence avoiding the need for normalization at all.
