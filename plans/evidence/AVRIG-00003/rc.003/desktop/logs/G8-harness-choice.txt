2. Prefer the Playwright harness when the project has one. The usual entry points are `npx playwright test` for the local stack, `npx playwright test --config=<sso-config>` for an SSO or federated login journey, and the project's own summary or report target for reading results.
3. Choose `agent-desktop` instead when the surface is a native window rather than a page: `apps/desktop`, `avatar/pet-desktop`, or any application a user operates directly. Decide which surface you are testing before writing the step, because a page loaded by a browser takes Playwright and a native window takes `agent-desktop`, and neither harness sees the other's surface.
