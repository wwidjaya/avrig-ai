## Notes on method

- The one `Start-Sleep -Milliseconds 1200` in this run sat between the Notepad close and the window-listing confirmation, as a settle delay for a read-only check. It was not used as an action wait, and it is recorded here rather than hidden. D12 is reported FAIL for a separate reason: `wait --text` cannot match text held in a textfield's `value`.
- The charmap.exe diagnostics (logs/F1-diag-*) are root-cause isolation for the `--stdin` defect, not substitute rows. They live under `logs/` for that reason.
- No `--headed` run was started. `type`, `focus`, `right-click`, `double-click`, and `triple-click` were not attempted, because none is needed by the matrix and physical input was not permitted.
- No application this run opened is still on screen: logs/D10-list-windows-final.txt is the confirmation.
