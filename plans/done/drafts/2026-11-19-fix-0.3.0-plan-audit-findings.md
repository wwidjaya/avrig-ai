## Key Detailed Design

### Program Design

This is a documentation change. The only target is the source plan file. The edits fall into four logical groups.

**Group 1, Evidence corrections (A1 to A5, A11).** Replace false or stale claims with verified text. The substantive design conclusions stay. The `build.rs` claim is the only substantively false item: `git ls-files --error-unmatch build.rs` succeeds in `avrig-api`, so the file is tracked and only `Cargo.lock` is modified. Five other claims carry stale line numbers.

**Group 2, Ownership and disjointness (A6 to A10, A12).** Give each shared or unowned file one owning phase. The three concrete conflicts are `packages/ui/package.json` (P4 and P6 both own it), `packages/api-client/dist` (rebuilt at P14 after the last clean gate), and `avrig-api/config/server.toml` (listed but unowned). Add a clean-tree assertion after P14 (CK5) to close the dirty-artifact loop. Guard CK2's own `git add -A` against unrelated working-tree content.

**Group 3, Modern Web Guidance integration (B1 to B10).** The analyst invoked `npx modern-web-guidance@latest search ...` and `retrieve ...` and read 12 guides: `dialog`, `light-dismiss-a-dialog`, `platform-controls-dismiss-dialog`, `prevent-page-scroll-under-modal-dialog`, `accessibility`, `html`, `css-layout`, `design-token-reactivity`, `dark-mode`, `animate-to-from-top-layer`, `persistent-top-layer-ui`, `navigation-drawer`. The plan is kept on Radix shadcn for ecosystem compatibility, with a recorded deviation and rationale, and the tests are rewritten as outcome assertions rather than implementation assertions. A Baseline Widely Available target is declared. Every fe phase P4 to P9 gains a mandatory MWG consultation step.

**Group 4, Deploy and guard semantics (A12, A11).** Assert the deployed `host` equals `127.0.0.1` rather than only byte-comparing, and rename V17 to reflect what it actually proves, with an accepted-risk note for the historical credential exposure.
